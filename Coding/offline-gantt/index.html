What this example teaches

  1. Date intervals: a booking occupies [start, end). One that ends on June 5 can be followed by another starting June 5.
  2. Clipping: bars are cropped to the visible window; inspection still shows the full booking.
  3. Conflicts: two bookings conflict only when they overlap on the same resource.

All resource names and DEMO IDs are invented. Changes exist only in this page and reset on reload. This is a separate teaching example, not the historical application or a production booking system.
